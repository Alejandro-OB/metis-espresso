# Compatibilidad de EKO 3.0.0 a 3.1.0

EKO 3.1.0 es una ampliación aditiva para perfiles sensoriales. Añade
`SensoryProfile`, `DeclaredSensoryProfile`, `TargetSensoryProfile` y sus
propiedades de procedencia y comparación. No elimina ni cambia el significado
de triples válidos de EKO 3.0.0; por ello no requiere un SPARQL Update para los
datos existentes.

Procedimiento:

1. conservar copia y versión del grafo 3.0.0;
2. cargar `ontology/espresso-dt.ttl` 3.1.0;
3. mantener evaluaciones existentes como observadas, sin convertirlas
   automáticamente en perfiles declarados u objetivos;
4. añadir perfiles únicamente cuando se conozcan su café y procedencia;
5. ejecutar las formas SHACL y `python tests/validate.py`.

No se debe inferir un perfil declarado desde una evaluación, ni crear un
objetivo copiando una descripción comercial. La migración semántica requiere
una afirmación nueva de la fuente o del barista.
